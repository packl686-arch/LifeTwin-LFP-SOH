# V10 private repeatability boundary

V10 used the locally held SNL LFP RPT bundle to test whether the withdrawn V7
dynamic update could clear a real repeated-measurement gate. The row-level
measurements, fitted noise parameters, condition summaries, and 1,024-draw
diagnostics remain private because the reusable publication scope has not been
made machine-readable.

The only public decision is fail-closed: the repeatability component did not
clear the frozen gate, the complete measurement system was not identifiable,
the 1,024-draw end-to-end stress did not qualify V7, and the effective dynamic
correction was exactly zero. V5 remains the champion.

This directory does not contain SNL measurements or numeric SNL-derived model
results. It does not create independent accuracy evidence or any Hithium claim.
