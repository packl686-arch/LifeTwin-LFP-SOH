## 1. 为什么先做这个实验

公开 Naumann 数据最长约 885 天，不能直接证明 15–25 年预测准确。继续在同一批已查看
结果上增加公式，只会提高拟合自由度，不会创造长期证据。本实验先回答一个更基础、也更
可证伪的问题：**当若干退化结构在前 730 天几乎无法区分、但在第 25 年显著分叉时，
模型结构分歧能否在不知道未来真值的情况下识别危险外推并主动拒绝？**

这是一项已知真值的合成机制压力测试，不是电化学数字孪生，也不是新的 LFP、海辰产品
或储能电站验证。通过只说明拒绝逻辑在预先声明的合成危险上有用；失败则直接否定当前
V1 分歧门控的准备度。

## 2. 冻结时间轴与数据单位

每个普通仿真 cluster 是一条独立抽取参数、独立生成噪声的潜在真值轨迹。时间点不是
独立样本，真值族也只是报告分层，不能增加统计样本数。

- 前缀点共 12 个：`0, 7, 14, 30, 60, 90, 120, 180, 270, 365, 540, 730` 天。
- 未来点共 8 个：`1095.75, 1461, 1826.25, 2556.75, 3652.5, 5478.75,
  7305, 9131.25` 天，最后一点按 365.25 天/年标记为 25 年。
- 预测器只接收前缀容量保持率和未来时间坐标，不接收真值族、参数或未来容量。
- 日零容量保持率固定为 100%。主评分对无噪声潜在真值计算；带噪未来观测只做次要
  敏感性检查，避免把测量噪声误当成结构误差。

## 3. 五个预先声明的真值族

公式中的 `t` 单位为天，容量保持率单位为百分点。参数分布与完整数值范围全部冻结在
JSON 中；实现不得看结果后缩窄范围。

| 真值族 | 冻结结构 | 要攻击的问题 |
|---|---|---|
| 单幂律 | `100 - a(t/365.25)^b` | 模型结构正确时的平滑参考 |
| 双幂律 | 快、慢两个不同指数的损失项 | 短期看似单机制，长期由第二机制放大 |
| 饱和项 + 慢幂律 | 早期项逐渐饱和，慢项继续增长 | 单幂律可能把早期速度永久外推 |
| 早期激活 + 幂律 | 暂时容量回升叠加不可逆损失 | 避免把早期回升解释为长期改善或快速衰减 |
| 晚期 knee | 幂律底座加 3–15 年后启动的平滑加速项 | 前 730 天没有直接看到拐点时的结构不可辨识性 |

所有抽样轨迹必须在完整网格上有限，日零恰为 100%，容量保持率位于 50%–105%，且
相邻检查点变化不超过 12 pp。除早期激活族外，其余族必须单调不增。不合格参数只能在
同一 cluster 的固定真值随机流内重抽；单 cluster 超过 10,000 次仍失败时，整个协议
执行失败，不能悄悄删掉困难样本。

观测噪声采用冻结的高斯 AR(1) 过程，标准差从 0.05–0.25 pp、相关系数从 0–0.8
独立抽取。按 20 个“前缀后未来”网格索引依次抽取标准正态创新，以
`e0=sigma*z0`、`ei=rho*e(i-1)+sigma*sqrt(1-rho^2)*zi` 递推，观测值为 `q+ei-e0`，日零再置为
100。AR 步长按观测索引而非日期间隔。主实验没有缺失值，也不在拟合前舍入。

## 4. 独立分区、seed 与 cluster

五个真值族在每个分区等量出现：

| 分区 | 每族 cluster 数 | 总 cluster 数 | 允许用途 |
|---|---:|---:|---|
| development | 100 | 500 | 实现检查，不形成最终结论 |
| calibration | 100 | 500 | 冻结最强均值基线和分歧阈值 |
| test | 200 | 1,000 | 一次性主终点评分 |
| audit | 100 | 500 | 不调参的方向复核 |

四个普通分区、匹配反例、随机拒绝比较器和 bootstrap 分别使用
`2026072201` 至 `2026072207` 的根 seed。真值与噪声 seed 由包含对应分区根 seed、真值族和
cluster 索引的 SHA-256 派生；模型则使用无随机 seed 的固定 Sobol 起点。真值族、真值参数、
分区 seed、未来值和 cluster ID 均禁止进入拟合、分歧或发行逻辑。任何 seed 碰撞、
cluster 跨分区重复或 test 真值提前暴露都会使本次执行作废。

这里的“独立”只指仿真抽样流和 cluster 不重叠，不代表获得了真实世界独立电芯证据。

## 5. 候选方法与比较器

候选 `lifetwin_bounded_structure_disagreement_gate_v1` 同时拟合六类只看目标前缀的结构：

1. 持久性；
2. 平方根时间；
3. 有界单幂律；
4. 饱和项 + 慢项；
5. 双幂律；
6. 晚期 knee 固定先验网格。

全部模型使用固定公式与边界、TRF 有界最小二乘、16 个无扰动 Sobol 起点和同一前缀
平方误差目标。参数并列时按固定规则决定，成员预测在评分前不裁剪。成员前缀 RMSE 必须
不高于最佳成员 `0.10 pp`，且最大前缀残差不超过 `0.50 pp`，才算“前缀相容”。至少
需要两个结构不同的相容成员；否则分歧分数记为正无穷并拒绝。候选均值是相容成员在每个
未来点的中位数，分歧分数是未来网格上成员最大–最小差的最大值。少于两个成员时仍用
有界幂律留下可审计 fallback 均值，但不得签发。

主选择性评价只在“至少两个可信结构族、分歧有限且全部未来均值有限”的硬资格池中，按
分歧从小到大排序并只发行 500 条。不合格轨迹永不用来填满名额；并列时按规范化前缀内容哈希排序。
这个 50% 是批量风险曲线上的实验操作点，
**不是可部署的绝对阈值**。

均值比较器固定为持久性、平方根时间和有界幂律。仅在 calibration 分区按平均轨迹 IAE
选择最强者，模型 ID 字典序打破并列，之后不得因 test 结果更换。拒绝比较器包括固定
10,000 个随机 50% 排名，以及只按最佳前缀拟合误差排序的 50% 拒绝策略。
时间指数收缩偏差不属于 V1 的成败范围，必须留给具有独立先验学习分区的新版本协议；
V1 不宣称检验了收缩的利弊。

## 6. 匹配前缀反例

另生成 200 个**单幂律 vs 晚期 knee 配对 cluster**。每对共享
`a in [0.2,0.9]`和 `b in [0.35,0.75]`；knee 侧另按固定顺序抽取
`t_knee in [1826.25,3652.5]`天、`k in [0.0015,0.0030] pp/day`，且 `w=30`天。

每对必须在 `0..730` 的逐日无噪声潜在曲线上同时满足：RMSE 不超过 `0.10 pp`、最大差不超过
`0.10 pp`，而 25 年真值差及未来网格最大差均至少 `5.0 pp`。每对只按上述参数法则提案一次，
不拟合、不搜索、不按长期分离度挑选。任一构造对不合格则本次协议执行失败，不得重抽。
匹配过程不能读取候选预测；一对中的两条轨迹共享同一噪声向量，以隔离结构歧义。
两成员以 `matched_prefix_counterexamples` 分区和不编码族别/侧别的不透明 ID 进入全部普通前缀、坐标、
预测、决策、成员诊断和真值包。pair/侧别/族别映射在预测承诺写入前保持密封，只在评分阶段的
`matched_prefix_pairs.csv` 中开启。

反例的拒绝阈值是 calibration 硬资格轨迹中升序第 250 个有限分歧分数，在反例评分前
冻结。只有严格大于阈值的有限分歧才计拒绝成功，拟合失败不能借正无穷得分。配对内两条轨迹不是两份独立证据，整对才是一个统计单位。

## 7. 三个共同主终点

“灾难性错误”预先定义为第 25 年候选均值绝对误差 `>= 5.0 pp`。轨迹 IAE 用未来
8 点按真实时间做梯形积分，再除以首末未来点跨度。

| 主终点 | 固定通过条件 |
|---|---|
| 50% 发行率的灾难风险降低 | 相对 10,000 个固定随机拒绝的平均灾难率至少降低 **30%**，且按真值族分层的 5,000 次 cluster bootstrap 单侧 95% 下界必须大于 0 |
| 匹配反例双侧拒绝 | 至少 **80%** 的合格配对中，两条轨迹都超过 calibration 冻结分歧阈值 |
| 已发行轨迹 IAE 非劣 | 候选减 calibration 选出的最强均值基线不超过 **+0.10 pp** |

三个主终点必须全部通过。还必须满足：test 中策略实施前至少存在 30 个灾难 cluster、
至少 500 个 test cluster 通过硬资格、得到全部 200 对合格反例、至少 95% test cluster 有有限候选均值，且 audit 分区灾难
风险降低方向不反转。

- 全部通过：记为 `success`。
- 任一性能或安全门槛未过，或 audit 方向反转：记为 `failure`。
- 灾难样本不足、反例不足或有限预测不足：记为 `inconclusive_not_success`，不得称成功。
- seed/哈希/分区/防火墙/产物完整性错误：记为 `void`。

非有限或模型失败轨迹必须硬拒绝；任何比较器若错误尝试发行它，按灾难错误计数，不得删行。
次要分析包括逐真值族误差、风险–覆盖曲线、灾难识别 AUROC、25%/75% 发行率、
前缀拟合误差拒绝比较、成员失败率和噪声敏感性。这些结果不能替代失败的主终点，也不能
用于重写 V1 门槛。

## 8. 结果防火墙与必交产物

执行顺序固定为：冻结协议/代码/环境/seed → 生成前缀包、未来坐标和密封真值包 →
只公开真值包 SHA-256 commitment → 冻结预测与拒绝决定 → 核对哈希后连接真值 →
一次性评分。

前缀、坐标、预测、决策、成员诊断和真值包都使用 JSON 中冻结的精确列顺序；任何未知列、别名或额外
oracle/真值字段均在拟合或评分前拒绝。必须发布：
`prefix_pack.csv`、`forecast_coordinates.csv`、`truth_commitment.json`、
`prediction_bundle.csv`、`decision_bundle.csv`、`prediction_commitment.json`、
`member_fit_diagnostics.csv`、`truth_pack.csv`、
`matched_prefix_pairs.csv`、`score_report.json`、`environment.json` 和
`exposure_log.json`。评分器必须先核验真值开启前单独写入的预测包与决策包字节哈希，再打开真值包；
对被篡改的当前对象重算一个新哈希不构成“已冻结”。模型失败作为拒绝记录，不能删行；结果必须同时报告总表、每个真值
族、每个未来点、成员数量和全部失败/偏离。

## 9. 宣称边界

若通过，唯一允许的核心表述是：**在冻结的合成真值族和选择性评价规则下，结构分歧
降低了 25 年灾难性外推风险，并能识别大部分匹配前缀反例。**

无论结果如何，均禁止把它描述为：

- 真实 LFP 的 25 年精度或覆盖保证；
- 海辰产品、个体电芯或储能电站验证；
- 独立外部数据确认；
- 完整电池物理机理证明；
- 可直接部署的 50% 发行阈值。

通过不会提高当前 LifeTwin 的真实数据证据等级。失败意味着当前 V1 分歧门控无法抵御
这些已经声明的合成危险，应保留负结果并重新提出 V2，而不是换 seed 或放宽阈值。
