# LifeTwin V0.15 长时域风险选择与部分可辨识实验预注册（V2）

冻结日期：2026-07-23  
冻结见证人：Jincheng Liu  
协议 ID：`synthetic_long_horizon_identifiability_v2`  
机器可读协议：[`configs/experiments/synthetic_long_horizon_identifiability_v2.json`](../configs/experiments/synthetic_long_horizon_identifiability_v2.json)

## 1. 为什么必须新建 V2

V1 是一次有效的阴性实验。它证明原始“最大结构包络宽度”有一定风险排序能力，
但没有达到预注册门槛，并在 `late_knee` 机制上反转。更重要的是，200 对反例
在 0 至 730 天具有相同可见信息，却通向明显不同的 25 年未来。任何确定性
前缀模型对相同输入都只能给出相同输出，所以“从同一前缀识别哪一侧会发生
knee”不是一个可实现的目标。

V2 不降低 V1 门槛，不更换 V1 seed，不改写 V1 结论。它提出三个不同的问题：

1. 把中心预测与风险判断分开后，透明风险头能否在固定 50% 发行率下降低灾难误差？
2. 在中心预测完全相同的条件下，预测时已经声明的运行工况能否提供额外风险信息？
3. 对真正不可辨识的同前缀未来，能否用有限且受宽度约束的同时预测集诚实覆盖多个分支？

V1 的全部分区、配对反例、系数与阈值均已暴露，只能用于形成上述假设，禁止
进入 V2 的训练、校准或成功判定。

## 2. 冻结顺序与信息防火墙

V2 使用严格分离的六阶段流程：

1. `D-center`：600 个全新 cluster，只拟合一个中心混合系数。
2. `D-risk`：另 600 个 cluster，在中心冻结后拟合两个主风险头及冻结比较器。
3. `C`：900 个 cluster，只做概率校准、均值基线选择和预测集扩张。
4. `T`：1,900 个 cluster，只做一次性主检验，其中 400 个来自训练和校准均未出现的新机制。
5. `A`：950 个 cluster，改变族比例、参数分布、工况分布和噪声后做不调参复核。
6. `M0/M1`：各 250 对，分别审计内在不可辨识性与可见工况的增量信息。

真值被物理拆成 center、risk、calibration、test、audit 和两类 matched truth
文件，不能用一个总表假装分阶段揭盲。中心训练并哈希冻结后，才允许打开
`risk_development_truth.csv` 产生灾难标签。风险系数冻结后，`C` 只能完成校准，
不能回改系数。`T`、`A`、`M0`、`M1` 的真值在
`model_state.json` 和全部预测文件写入并哈希承诺前不得打开。预测 API 不接受
真值文件、真值族、未来 SOH、pair side 或评分对象。

## 3. 两个风险实验臂

### Arm A：`prefix_only`

只使用 0 至 730 天的 12 个 SOH 观测，以及由这些观测确定性计算的 14 个
结构和前缀特征。成功数、失败数和边界命中率都按固定结构族而非 variant 行计，
有效形状数是族代表中的不同量化签名数。它代表“只有短期 SOH 曲线”的信息边界。

### Arm B：`visible_stress`

在 Arm A 的 14 个特征后固定追加 8 个预测时可见字段：历史温度、SOC、DOD、
年 EFC，以及 730 天之后合同运行情景中声明的温度、SOC、DOD、年 EFC。
这里的未来工况是已知的条件情景，不是未来实际测量值。V2 检验的是“模型能否
利用已声明情景”，不假设未来一定按计划执行。

两个臂使用字节级相同的中心预测、共同硬资格池和相同发行数量。唯一资格定义为：
12 个前缀、8 个预测点、8 个真实工况和 8 个 placebo 完整有限，至少两个可信
结构族成功，中心及全部冻结特征有限。训练、test、audit、负对照和所有比较器
只能引用这一套定义。任何收益不得通过更换中心、缩小资格池或改变覆盖率获得。

## 4. 合成真值与外推挑战

六个核心族为 `single_power`、`dual_power`、`saturating_plus_slow`、
`early_activation_plus_power`、`late_knee` 和新增的
`linear_drift_plus_power`。另设两个从不进入 `D-center`、`D-risk` 或 `C`
的新机制：`smooth_broken_power` 与 `saturating_logistic_knee`。前者是退化指数
发生平滑转折的 broken-power 结构，不是把既有饱和结构换一个参数范围。

工况在真值参数之前独立生成并冻结。历史工况影响 0 至 730 天基础损失，声明的
计划工况只影响 730 天之后的增量损失。另有 8 个相互独立的 `placebo` 字段完全
不参与真值，用于负对照。若真值不满足支持约束，只能在固定工况下重抽真值参数，
不得重抽工况。

审计分区不是普通的新 seed：它使用不等族比例、参数上下四分位混合、U 形工况
分布及更高测量噪声。两个结构新机制同时进入主 test 和 audit，使 V2 不能只在已经
暴露的 V1 生成器上成功。

## 5. 中心预测

结构库保留 V1 的 persistence、sqrt-time、bounded-power、saturating-plus-slow、
dual-power 和 late-knee grid，并补充 `early_activation_plus_power`。V1 共用成员的
公式、边界、Sobol 起点、求解器容差及 tie-break 由 V1 配置的双 SHA-256 固定，
实现前必须通过共用输入逐值回归测试。

所有结构统一通过 `RMSE<=1.0 pp`、最大前缀残差 `<=1.5 pp`、未来值位于
`[40,105]` 的可信度门。先按原始 float64 字节删除精确重复，再把每个坐标按
`0.25 pp`、round-half-even 量化并按完整八维签名聚合。每个结构族总权重相等，
late-knee 的大量 grid variant 只能在族内分配权重，不能获得几十倍投票权。
中心只使用每族一个代表，并再次按形状签名去重。复制 variant、改名或调换顺序
不得改变聚合结果；失败族不会伪装成新的 sqrt 结构支持。

中心仅拟合一个透明系数：

```text
center_h = sqrt_h + beta * (library_h - sqrt_h), 0 <= beta <= 1
```

若 `x=library-sqrt`、`y=truth-sqrt`、`N=4800`，则
`beta=clip(sum(x*y)/(sum(x*x)+0.01*N),0,1)`。它对应八时点 MSE 加
`0.01*beta^2`，而不是含义不同的 SSE 正则。
中心冻结后不得因风险标签、test 或 audit 结果改变。

## 6. 风险头

灾难标签定义为冻结中心在 25 年点的绝对误差 `>=5 pp`。两个臂均使用标准化
L2 logistic regression：`lbfgs`、`C=1`、无类别权重、`max_iter=10000`、
`tol=1e-10`。均值、标准差和系数只来自 `D-risk`。有限常量特征统一变换为 0，
其系数固定为 0，不会因为常量计数让实验直接失效。`C` 上的 isotonic map
只用于概率展示，所有主排名都使用原始线性 risk score，避免平台造成的 ties。

Arm A 的 14 个冻结特征覆盖：结构成功和失败数、最佳前缀 RMSE、去重形状分位
宽度、有效形状数、参数边界命中率、廉价 leave-730-out 误差、中心 25 年值、
中心与 sqrt 差、早期和近期下降、曲率，以及 10 至 25 年尾部分歧增长。
Arm B 只追加前述 8 个工况字段，不做特征选择，不加交互项。

## 7. 部分可辨识预测集

在每个预测点按“族等权、族内签名等权”的经验测度取 inverted-CDF `q05/q95`
作为基础带。对每个 calibration cluster
计算真值超出整条八时点基础带的最大距离。900 个分数升序排列，使用
`ceil((900+1)*0.90)=811` 号顺序统计量同时向两侧扩张，得到名义 90% 的轨迹级
split-conformal 预测集。必须有 900/900 个有限 calibration score；不能一边
写死 `k=811`，一边只使用 855 个样本。

核心 test 的 1,500 个 cluster 和 M0 的 250 对始终保留在覆盖分母。任何一个
八时点区间缺失或非有限都直接令相应主终点 `inconclusive_not_success`，不能删行。

区间评分使用未裁剪原值。不得先裁剪到 `[50,105]`。完整真值支持 `[50,105]`
宽 55 pp，是必须报告的无信息比较器。该预测集只对冻结核心混合分布有
split-conformal 含义，不是物理可辨识域，也不保证覆盖真实电芯或新机制。

## 8. 两类配对审计

### M0：内在不可辨识

250 对成员共享完全相同的前缀、噪声和全部工况。一侧为平滑幂律；125 对的
另一侧增加前缀后严格为零起步的 piecewise-linear knee，另 125 对增加候选库
中不存在的 compact smoothstep 有界损失。25 年分离至少 5 pp。两侧所有
可见内容相同，因此在 ID 归一化后必须分别满足 `A_left=A_right` 和
`B_left=B_right`；共享中心和区间也必须 left/right 相等。Arm A 与 Arm B 是两个
不同风险头，不要求跨臂 risk、hash 或 decision 相等。M0 的两类曲线均须有限、
位于 `[50,105]` 且 25 年分离至少 5 pp；作为刻意的突变歧义压力测试，它单独
报告最大相邻网格变化，不套用普通队列的 12 pp 筛选。正确问题不是区分左右，
而是同一个预测集能否同时覆盖两条八时点未来。

### M1：计划工况增量信息

250 对成员按六个核心族固定配额，共享基础真值、历史工况、前缀和噪声，只改变
预测时已知的未来运行情景。Arm A 必须 250/250 严格同分，这是信息防火墙门。
揭盲后仍报告 Arm B 对 25 年中心绝对误差的成对排序，误差或 score tie 都按错误
计且不删除 pair；但它与 logistic 的二分类目标不完全相同，因此降为机制 sanity
check，不参与 V2 成功判定。独立 test 上的 B-A 才是工况增量主证据。

## 9. 主终点

test 源队列共 1,900 个 cluster，实际共同资格池允许为 1,805 至 1,900；无论实际
资格数多少，每个臂都严格发行风险最低的 950 个。五项必须全部通过：

| 终点 | 冻结门槛 |
|---|---:|
| Arm B 相对 10,000 个同池随机排名的灾难风险降低 | `>=30%`，且 5,000 次八族分层 bootstrap 单侧 95% 下界 `>0` |
| Arm B 风险降低减 Arm A 风险降低 | `>=10` 个百分点，且配对 bootstrap 单侧 95% 下界 `>0` |
| 六核心族 test 的八时点同时覆盖率 | `>=85%`，且单侧 95% 下界 `>83%`；cluster 最大八时点宽度中位数 `<=40 pp`、95 分位 `<=50 pp` |
| M0 中同一区间同时覆盖两侧全部八时点 | `>=80%`，且单侧 95% 下界 `>75%`；pair 最大八时点宽度中位数 `<=40 pp`、95 分位 `<=50 pp` |
| Arm B 已发行样本上的中心 IAE 相对 calibration 最强均值基线 | 劣化 `<=+0.10 pp` |

附加安全门：任何至少含 30 个灾难样本的 test 族，Arm B 族内风险降低不得为负；
两个新机制合并子集的 Arm B 风险降低必须 `>0`，B-A 增量不得为负；
`late_knee` 不得再次反转。

audit 不重训、不重校准，严格发行 475 个，要求 B 风险降低 `>0`、B-A `>0`、
新机制方向不负、`late_knee` 按族内 50% 独立发行时不反转，且 IAE 非劣仍为
`<=+0.10 pp`。同一批 M0/M1 不会被重复包装成“独立 audit”。

## 10. 比较器与负对照

所有策略使用同一中心、共同资格池和相同发行数，并明确发行风险值最低的一端。
必须报告：随机排名、前缀 RMSE、V1 最大包络宽度、中心与 sqrt 差、Arm A、
`D-risk` 上确定的最强单特征排序、协议已知的 `S_plan` 单指标，以及
`Arm A + S_plan` 简单 logistic。若复杂头不胜简单 stress-index，只能报告工况
信号有效，不能宣传复杂结构占优。

两个负对照不得删除：

1. 在 test 真值族内对八个工况字段做 10,000 次确定性置换，不重拟合模型；实际
   B-A 增量必须高于至少 99% 的置换增量。
2. 用 8 个相互独立、完全不进入真值的 placebo 字段训练一个相同 22 维比较头；
   placebo-A 增量绝对值必须小于 5 个百分点，且配对 bootstrap 双侧 95% 区间
   必须包含 0。严重负向结果不能靠单边 `<5%` 自动过关。

## 11. 成功、失败、无结论与作废

`success` 要求五个主终点、族别和新机制安全门、负对照、完整性门及 audit
方向门全部通过。

以下情况为 `inconclusive_not_success`：test 共同池少于 1,805、audit 少于 903、
calibration 不是完整 900；有限中心少于 98%；`D-risk` 或 calibration 的正负标签
任一少于 60；test 灾难 cluster 少于 60；新机制少于 30；需要审计的
`late_knee` 灾难 cluster 少于 30；任一 matched experiment
不足 250 对；拟合、isotonic、conformal 或任一必需 bootstrap 复制不可定义。

任何主终点、安全门、负对照或 audit 门未达到冻结要求均为 `failure`。

以下情况直接 `void`：使用 V1 行或状态训练；预测承诺前打开 test/audit/matched
真值；seed、cluster 或 partition 重叠；协议、源码、环境或工件 hash 不一致；
Arm A 看到工况；任何臂看到族别、参数或未来 SOH；看结果后更换 seed、特征、
阈值、族比例或排除 cluster；缺少承诺工件。

阴性或无结论结果仍必须发布同样的总体、族别、新机制、配对、覆盖、宽度、
负对照和失败记录。

正式运行从生成前开始追加 `exposure_log.jsonl`，记录 commit、配置 hash、truth
和 prediction commitment、已打开真值及退出状态。预测承诺后不得重新生成；
揭盲后的不可恢复中断记为无结论，不能让失败尝试从最终材料中消失。

## 12. 声明边界

即使 V2 全部成功，也只能说明：在冻结的合成机制中，模型能利用被明确植入且
预测时已声明的工况信息改进风险排序；对完全相同的可见信息，有限预测集比伪称
识别未来分支更诚实。

V2 不能证明真实 LFP 25 年精度、真实工况因果规律、海辰产品或电站验证、个体
电芯保证、外部数据确认、可部署 50% 阈值或当前真实数据证据等级提升。
`40 pp` 宽度门槛也是受已暴露 V1 结果启发的可证伪假设，不是独立建立的物理
容差。
