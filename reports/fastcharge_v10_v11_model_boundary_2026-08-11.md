# FastCharge V10/V11 模型边界收口报告

日期：2026-08-11

负责人：Jincheng Liu

结论：保留 V5，退役 V7 动态修正，不推进本轮 Delta-Q 挑战者

## 1. 为什么做这两组实验

V7 在 41 个训练电芯内部出现过 `9/9` 激活改善，但冻结后的微小噪声审计失败。
因此下一步不能继续调门槛，而要回答两个互斥问题：真实重复测量是否足以支持动态
修正；如果不能，加入电压曲线形状信息是否能稳定提高冻结 V5。

## 2. V10：真实重复性参数的失效优先审计

V10 从 SNL 周期汇总中提取同一 RPT visit 内的重复容量测量，校正组内中心化造成的
方差收缩，并用留一物理电芯对数分数在 Gaussian 与固定自由度 Student-t 族之间
选择噪声模型。它只能识别 visit 内重复性和测量顺序效应，不能识别共同偏置、跨
visit AR(1)、长期漂移、测试设备桥接偏差或温箱偏差。

私有审计没有通过冻结的重复性与顺序效应门槛。随后用该私有参数执行 1,024 次完整
V5 重拟合、12 近邻重选和 P60/P100 中心重建；V7 仍未取得资格，最终修正逐点精确
回退为零。由于 SNL 的可复用公开范围尚未机器可读，仓库只公开决策边界，不公开
测量行、参数和数值诊断。该结果不是准确率评估。

## 3. V11：Delta-Q 多模态挑战者

V11 严格只读取 `cell_id`、cycle 10/100 坐标和六个登记的 `Delta Q(V)` 特征，CSV
中的 cycle life、数据集划分和其他结局字段没有被读取。实验只使用 41 个 MATR
训练电芯；每一折的验证电芯同时从 pair target、pair reference 和 robust scaler
中移除。81 个已暴露评估电芯没有再次使用。

| 方法 | 五折 P100 MAE | 相对 V5 | 改善电芯 | 物理电芯 bootstrap delta 95% 区间 |
|---|---:|---:|---:|---:|
| 冻结 V5 | 0.24360 pp | - | - | - |
| Delta-Q 只进残差模型 | 0.24385 pp | -0.10% | 46.34% | [-0.01094, 0.00915] pp |
| Delta-Q 同时进入残差与近邻几何 | 0.24183 pp | +0.73% | 46.34% | [-0.01845, 0.01062] pp |

较好的候选仍远低于 5% 改善门槛，区间跨零，P90 逐电芯退化超限，而且在一个制造
批次留出方向退化 `0.00659 pp`。因此两个候选都不冻结为新盲测模型。

## 4. 工程结论

当前瓶颈不是“模型还不够复杂”。在现有公开队列上继续堆动态门控或曲线特征，没有
产生跨电芯、跨批次稳定收益。最高价值下一步是把冻结 V5 接入海辰批次独立的私有
校准和一次性 locked test；预测前先执行不接受真值库参数的 prefix readiness 审计，
域外或材料不完整时停止，而不是通过调阈值获得一个更好看的回顾性结果。
