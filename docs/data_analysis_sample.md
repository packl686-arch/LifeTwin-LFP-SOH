# 数据分析样本：从短期前缀到长期 SOH 轨迹

本样本使用仓库内可再分发的 Naumann LFP/石墨日历老化条件均值表，展示如何
从问题定义、数据审计、模型比较、异常定位走到受限结论。完整脚本位于
[`showcase/analyze_phase8_results.py`](../showcase/analyze_phase8_results.py)。

## 1. 分析问题

1. 只看到目标条件前 10 次容量检查时，能否预测之后的完整容量轨迹？
2. 从其他温度和 SOC 条件学习的共性规律，能否帮助目标条件？
3. 低 SOC 早期容量回升是否会破坏普通单调衰减模型？
4. 激活偏移模型的改善是否依赖唯一的时间常数？

## 2. 数据概况

| 项目 | 数值 |
|---|---:|
| 独立统计单位 | 17 条温度/SOC 条件均值轨迹 |
| 观测行数 | 595 |
| 每个条件的来源电芯 | 3 个物理电芯的公开均值 |
| 最长观测时间 | 885.04 天 |
| 主分析前缀 | 前 10 次检查，约 136.95 天 |
| 未来评估终点 | 最长约 885 天 |

这 595 行不能当作 595 个独立样本；正式比较以条件轨迹为单位。

## 3. 比较方法

- **传统平方根曲线**：每个目标条件单独拟合固定 `sqrt(time)` 形状。
- **层次幂律 V2**：从训练条件学习温度/SOC 先验，再用目标前缀同时更新幅度
  与时间指数。
- **门控激活 V3**：当目标前缀出现负容量损失且正时间观测不少于 7 个时，
  使用“不可逆幂律老化 - 饱和激活偏移”；否则逐点回退 V2。

所有方法只读取 `checkup_index < 10` 的训练和目标标签。未来坐标可以用于生成
预测时间点，但真实未来容量只在预测包冻结后用于评分。

## 4. 结果

| 场景 | 平方根 IAE | V2 IAE | V3 IAE | V3 相对 V2 |
|---|---:|---:|---:|---:|
| 未见温度层级 | 1.1287 pp | 0.4801 pp | 0.3662 pp | -23.72% |
| 40 C SOC 插值 | 1.2864 pp | 0.6907 pp | 0.2097 pp | -69.64% |

![Model and tau comparison](assets/phase8_results.png)

V3 的总体均值改善由少数低 SOC 条件驱动：主前缀触发条件为
`T25_SOC0`、`T40_SOC0` 和 `T40_SOC12.5`。其余条件与 V2 完全相同。因此，
“均值降低”成立，但“普遍条件都更好”不成立。

## 5. Tau 敏感性

| tau (day) | SOC 插值 IAE | 未见温度 IAE | 两场景均优于 V2 |
|---:|---:|---:|:---:|
| 3 | 0.3764 | 0.4261 | 是 |
| 5 | 0.3183 | 0.4042 | 是 |
| 7 | 0.2097 | 0.3662 | 是 |
| 10 | 0.2261 | 0.3885 | 是 |
| 14 | 0.3824 | 0.4658 | 是 |
| 20 | 0.5525 | 0.5538 | 否 |
| 30 | 0.7196 | 0.6493 | 否 |

`3-14 day` 的方向较稳定，但更长时间常数会反转，说明时间常数仍需要独立数据
验证。7 天是在查看前一阶段异常后确定的开发值，不能写成无偏最优值。

## 6. 可复现命令

```powershell
.\.venv\Scripts\python.exe showcase\analyze_phase8_results.py
$env:PYTHONPATH='src'
.\.venv\Scripts\python.exe scripts\run_calendar_v3_activation_development.py
```

第一条命令从已发布的聚合结果重建图表；第二条从 CC BY 4.0 的规范化观测表
重新执行完整实验。runner 拒绝覆盖已有输出，重复执行时需要指定新目录。

## 7. 分析结论

当前数据支持“机制门控值得进入独立验证”，不支持“已证明低 SOC 通用机理”或
“已经可以预测海辰电芯 15-25 年”。这一区分是本分析样本最重要的结论。
