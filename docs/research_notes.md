# 研究笔记与关键决策

## 研究主线

LifeTwin 的研究过程不是不断堆叠复杂模型，而是让每次失败决定下一次最小必要
改动：先建立可解释基线，再检查时间泄漏、跨工况迁移、不确定性和局部失效，
只有证据指向具体缺项时才增加模型自由度。

## 决策记录

### 决策 1：不使用 full-history 条件迁移证明“短推长”

最初的跨条件模型可以看到训练条件完整的 885 天历史，即使目标条件只给短期
数据，也会间接获得未来形状。这适合检验工况迁移上限，却不能回答所有条件都
只有短历史时怎么办。正式协议因此改为 global landmark：训练和目标条件在同一
检查点截断。

### 决策 2：固定平方根不是最终主模型

Naumann 论文和大量经验模型采用接近平方根时间规律，但目标条件的前缀指数会
随工况和观测窗口变化。Phase 6 让温度/SOC 应力面提供参数先验，再用目标前缀
更新幅度与指数。`p=10` 平均误差明显下降，但 SOC 场景仍有一个关键失败条件。

### 决策 3：先定位失败，不继续盲调超参数

`T40_SOC12.5` 的前两次正时间检查出现负容量损失，即容量相对初值上升。
前缀自由幂律指数约为 1.0917，而使用完整未来的诊断 oracle 约为 0.7960；温度/
SOC 先验约为 0.8373，方向反而接近 oracle。结论是早期形状失配，而不是应力
先验方向错误。

### 决策 4：把早期激活与不可逆老化分开

Phase 8 使用：

```text
loss(t) = exp(a) * t^b - c * (1 - exp(-t / tau))
```

第一项表示不可逆老化，第二项表示逐渐饱和的早期激活/基线偏移。该表达式是
现象学模型，不等价于已经证明具体电化学反应。

### 决策 5：复杂模型必须有启用证据

无门控激活模型在总体均值上更低，但会改变全部条件，并使部分普通条件变差。
主方案因此要求同时满足：前缀存在负容量损失、至少 7 个正时间观测。否则回退
冻结 V2。门控牺牲一部分平均收益，换取更小的错误启用范围。

### 决策 6：不把不确定性画得比数据更自信

Phase 7 的条件级有限样本校准显示，95% higher-order quantile 至少需要 19 个
校准条件，而当前最多 16 个。系统选择回退 `[0,100]` 物理范围，而不是伪造
有限区间。这个结果不好看，但比错误的置信度更有工业价值。

### 决策 7：landmark 必须在相同未来窗口比较

不同前缀若各自从下一检查点预测到终点，预测窗口长度并不相同，不能据此判断模型
何时真正获得信号。新增协议把 `p=5/8/10/14` 全部限制在检查点 14-34，并同时要求
两场景均值改善、逐条件零退化和唯一改善条件数。只有 `p=10` 满足，但数据结果早已
被查看，因此记录为回顾性信号点，确认点保持为空。

### 决策 8：残差只能修正已暴露的结构误差，不能吞掉机理模型

V4 没有把 595 行观测交给大黑盒，而是在层次机理均值上增加一个 landmark 锚定、
时间支持受限、幅度上限为 `2 pp` 的低维残差。残差训练采用 7 个训练条件的
leave-one-condition-out 预测误差；校准和测试条件不参与残差拟合。这样既允许修正
系统性曲率偏差，也保留回退、支持范围和状态哈希的可审计性。

### 决策 9：区间按路由和轨迹校准，证据不足就拒发

specialist 与 fallback 的误差分布不同，不能混在同一个校准池。V4 按实际均值路由
分区，并用整条轨迹最大标准化误差计一个校准分数。fallback 只有 5 个条件，因此只
能形成 80% 诊断分位数；specialist 只有 1 个，所有请求覆盖率都不可用。即便回顾性
诊断区间可算，运营发行仍因证据复用和缺少长期独立队列全部拒绝。

### 决策 10：独立短期负结果也必须公开

Geisbauer 队列许可明确且有 15 个独立 LFP 电芯，但只有 120 天、60 C 和三个 SOC。
冻结方法总体 IAE 为 `3.9735 pp`，目标前缀平方根为 `3.8852 pp`，主候选没有胜出；
100% SOC 的迁移最差。该结果被保留为外部应力筛查，既不重调协议，也不包装为长期
验证。它否定了“源域层次先验可直接无条件迁移”的假设。

## 被拒绝或降级的方案

| 方案 | 处理 | 原因 |
|---|---|---|
| 单一固定平方根曲线 | 保留为基线 | 无法自适应曲线指数和低 SOC 早期形状 |
| 所有条件无门控启用激活模型 | 降为诊断 | 参数更多，普通条件存在不必要改动和变差 |
| 用目标未来选择 tau | 禁止作为正式调参 | 会把开发结果包装成确认结果 |
| 把 595 行当独立样本 bootstrap | 拒绝 | 真实独立单位只有 17 条条件轨迹 |
| 把 `[0,100]` 的 95% 覆盖称为成功 | 拒绝 | 这是样本不足的回退，不是模型精度 |
| 直接迁移消费/动力电池深度模型 | 暂不采用 | 数据规模、工况和任务定义不匹配 |

## 当前冻结假设

- 主前缀：10 次检查。
- 主模型：机制门控目标前缀激活偏移混合模型。
- 比较器：冻结层次幂律 V2。
- 激活时间常数：7 天，明确标注 post-hoc。
- 门控：负容量损失证据且至少 7 个正时间观测。
- 统计单位：条件轨迹，不是观测行。
- 回顾性信号 landmark：`p=10`；确认 landmark：空。
- V4 残差：训练条件 LOCO、landmark 锚定、`2 pp` 上限、禁止超出训练时间支持。
- 区间：按均值路由和条件轨迹校准；证据复用时禁止运营发行。
- 确认状态：等待独立长期数据。

   负结果并定位是电芯域差异、门控失效还是时间常数失配。

## 2026-07-22：入围后入口与下一项研究决策

### 决策 11：先补真实推理入口，不在同一 outcome 上继续争小数

三路独立审计一致认为，v0.12 的最大短板是“评委可以复现实验，但不能提交一个目标
前缀实际得到决策”。v0.13 因此不晋升新均值模型，而是把相同 V4 数值路径提升为
严格 JSON 请求、Python API、CLI 和自包含 Judge Console。未来坐标不能出现容量字段；
测试条件未来结果可被完全遮蔽；域外、异常前缀和拟合失败不泄露研究均值，运营证据不足
继续返回 `abstained`。可操作性提升不能被解释为证据等级提升。

### 决策 12：下一项模型研究必须先回答“长期结构是否可辨识”

短前缀上的幂律、饱和模型和晚期 knee 可以几乎重合，却在 15–25 年产生完全不同的
终点。继续在 Naumann 上选一个更好的公式会重复使用 outcome，且无法暴露这种结构
不可辨识性。下一项实验冻结为 `synthetic_long_horizon_identifiability_v1`：

- 真值族包括纯幂律、平方根加线性、饱和、早期激活和前缀后的晚期 knee；
- 前缀为 90/180/365/730 天，评分点为 3/5/10/15/25 年；
- 比较固定平方根、当前 V2、固定物理指数收缩、双机制和饱和候选；
- 用候选长期预测的结构分歧形成 selective risk–coverage 曲线；
- 50% 发行率时，分歧拒绝须较随机拒绝降低至少 30% 灾难性错误；
- 必须构造 730 天内差异不超过 0.1 pp、25 年差异至少 5 pp 的匹配前缀反例。

无论成功或失败，该实验都只能说明合成机制压力测试结果。它不能替代独立 LFP 数据，
但能检验系统有没有在本来无法识别长期结构时仍然给出虚假窄区间。
