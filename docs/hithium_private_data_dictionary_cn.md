# 海辰私有数据接入字典与冻结清单

## 使用原则

数据保管人先用不含容量的元数据冻结批次分区，再生成开发轨迹、预测前缀和隔离真值库。模型进程不得读取校准或锁定测试的未来容量。字段缺失、单位不明或EFC口径未确认时必须停止，不得猜测补齐。

## 当前可执行必填字段

| 类别 | 字段 | 口径 |
|---|---|---|
| 身份 | `record_id`、`cell_id`、`batch_id`、`condition_id` | 脱敏但稳定；物理电芯和生产批次不可跨分区 |
| 产品 | `cathode_chemistry` | 当前仅接收LFP |
| 工况 | `temperature_c` | 老化环境温度，不以RPT室温替代 |
| 工况 | `min_soc_pct`、`max_soc_pct` | 老化SOC窗口，用于计算DOD |
| 工况 | `charge_c_rate`、`discharge_c_rate` | 老化过程倍率 |
| 坐标 | `visit_index` | 每个电芯从0开始连续的标准RPT序号 |
| 坐标 | `elapsed_days` | 自试验起点累计自然日，严格递增 |
| 坐标 | `equivalent_full_cycles` | 按企业冻结公式计算的累计EFC，严格递增 |
| 容量 | `capacity_ah` | 标准RPT容量，不使用日常部分循环吞吐代替 |
| 容量 | `reference_capacity_ah` | 冻结的SOH归一化基准 |
| 质量 | `quality_status` | 当前正式流程仅接收`accepted` |

## 建议同时保留的企业字段

产品型号、额定能量、产线、测试通道、设备编号、累计充放电Ah/Wh、静置策略、RPT温度与倍率、维护记录、测量不确定度和异常原因。它们先进入受控原始区，不应在未经协议修订时直接改变模型输入。

## V4未来计划字段

每个电芯和landmark需要完整提供冻结EFC网格上的计划：`forecast_elapsed_days`、`forecast_equivalent_full_cycles`、计划温度、SOC上下限、充放电倍率、场景ID、来源、角色和声明时点。正式候选只能使用在预测landmark之前已声明的计划。

`realized_future_schedule`必须标记为`oracle_upper_bound`。它可以评估“如果未来工况完全已知，方法最多能改善多少”，但不能成为部署精度或主模型晋级证据。计划表不允许出现容量、SOH、RUL或失效标签。

## 冻结前确认问题

1. EFC由额定容量、初始容量还是动态容量计算，充电和放电吞吐如何折算？
2. SOH分母使用出厂容量、首次RPT容量还是产品额定容量？
3. RPT的温度、静置、CCCV截止电流和倍率是否跨批次一致？
4. `batch_id`能否代表真正独立生产批次，是否还需按产线、测试柜或站点分组？
5. 至少有多少独立批次，以及每个电芯在最大landmark后有多少未来RPT？
6. 哪个身份保管真值库，预测身份是否在ACL层面无法读取？
7. 未来运行计划是在预测前制定，还是从测试结束后回放获得？

全部答案、配置哈希、数据清单哈希和双人复核记录完成后，才可以生成校准预测。锁定测试配置一旦冻结，不得因结果不理想而重新划分。
